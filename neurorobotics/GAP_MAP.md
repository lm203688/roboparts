# 神经控制前沿空白地图（GAP_MAP）

> 情报层 · 公开来源汇编（2025-2026）· 非 RoboParts 实测 · 逐条带出处
> 机器可读版本见 `neurorobotics/source.json` → `api/neurorobotics.json`

## 0. 心智模型（先校准，再谈空白）

不是「神经元取代大模型」，而是**分层闭环**：

- **认知 / 规划层**：LLM（世界模型、语言推理）—— 这部分大模型更合适，不要替。
- **脉冲控制层（SNN）**：事件驱动、反射、运动基元、低功耗—— 神经形态擅长的低层。
- **躯体层**：事件相机、触觉皮、仿生执行器—— 开放标准件生态恰恰是空缺。

「果蝇打游戏」是**接口演示**不是「脑在玩」：像素→感觉神经元、活动→按键、受伤→多巴胺奖励，
每一步都是工程师定义；原话是「它还是不擅长 Doom」，无稳定学习曲线，且非意识上传。

## 1. 已被卡死的两条路（我们不做）

| 轴 | 玩家 | 为什么我们不做 |
|---|---|---|
| 全脑 / 连接组仿真（造脑） | Eon（果蝇 12.5 万神经元，95% 行为预测）、DeepMind（RL 飞）、Google/Janelia（MaleCNS v1.0，16.67 万神经元）、EPFL（NeuroMechFly 躯体） | 需连接组数据 + 超算 + 躯体模型，重资产、强学术壁垒 |
| 神经形态芯片（流片） | Intel Loihi 2、BrainChip Akida、SynSense Speck/Xylo、SpiNNaker 2 | 已商用化，无差异空间，重资本 |

## 2. 开放空缺（我们要填的）

### GAP-G1 · 开放躯体 / 执行器标准件生态缺失 ⚠️ 高
- 脑（FlyWire / MaleCNS）已公开，**身体没有开放标准件生态**。
- Eon 自述「无法追踪真实运动神经元，因为身体未扫描」(m2now)。
- **RoboParts 切入点**：机械兼容（ISO 9409-1）已是现成底座，向「神经机器人躯体/执行器/连接器」延伸。

### GAP-G2 · 神经控制器↔躯体 无声明式适配器规范 ⚠️ 高
- 果蝇打游戏每次**手工接线**（DOOMFLY / Stonkfly 均为一次性映射）。
- 没有可移植、可校验的格式。
- **RoboParts 切入点**：`signal_interface.schema.json`——把机械兼容延伸到「脉冲/感觉/运动信号契约」。

### GAP-G3 · LIF 模型无可塑性 = 无长期记忆/学习
- 当前具身仿真用泄漏积分发放近似，突触权重静态（仅少数奖励通道可塑）。
- 仿真体不能形成长期记忆（m2now）。

### GAP-G4 · SNN 训练难 + 生态碎片化
- 脉冲不可微 → 替代梯度 / ANN→SNN 转换 / 局部 STDP；ImageNet 仍落后 ANN。
- 框架分散（Lava/Nengo/Norse/snnTorch），仅 NIR 做部分互操作（7 仿真器 + 4 硬件）。

### GAP-G5 · 规模扩张算力墙 ⚠️ 高
- 小鼠脑 ~7000 万神经元（果蝇 560×），人脑 ~860 亿；复杂度非线性。
- 谁能在中端市场参与取决于每突触成本曲线。

### GAP-G6 · 连接组是死脑快照，感觉/奖励映射为人定义
- 连接组是固定接线图非活体状态；「像素→刺激、活动→动作、奖励如何定义」都是工程师决定。

### GAP-G7 · 能效优势仅在神经形态硬件成立
- 病毒演示多跑 Mac Studio / GPU，实际更费算力；能效 2-3× 仅兑现于 Loihi/Akida。

## 3. 谁在做（竞品/合作方地图）

| 主体 | 焦点 | 方法 | 立场 |
|---|---|---|---|
| Eon Systems | 全脑仿真→具身（果蝇→小鼠） | 连接组派生动力学（非 RL） | 行为由生物接线涌现 |
| DeepMind | 果蝇神经通路→仿真躯体 | 强化学习（非连接组派生） | trial-and-error 优化涌现 |
| Google/Janelia | 连接组测绘（MaleCNS v1.0） | EM+AI 重建+人工校对 | 公开基础设施 |
| EPFL | 物理仿真躯体（NeuroMechFly v2） | 生物约束物理引擎 | 为脑仿真提供躯体 |
| Intel | 神经形态硬件 + Lava | 数字脉冲芯片 | 能效边缘推理 |

## 4. 我们的占位策略

1. **不造脑、不造芯片**——做脑×体之间的**标准与情报层**。
2. **GAP-G1 + GAP-G2** 是工程可填、且资产直接咬合的：RoboParts 机械兼容 + 新增信号接口契约。
3. **GAP-G3~G7** 是情报层标注（诚实边界），不投入工程，但持续跟踪。本模块的 gap 发现
   由 RoboParts 自身数据闭环完成；若 SwarmLabs 等外部项目需引用，须各自独立运行
   （详见 README「与 SwarmLabs 的关系 · 项目独立原则」），不共享源文件、不互相依赖。
