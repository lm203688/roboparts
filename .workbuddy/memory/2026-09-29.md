### 8.2 关键发现：`.superdex_bot` 是 JSON 声明式格式

**不是 URDF/xacro，是纯 JSON 声明式**——RoboParts 可以直接解析，不需要外部库。

两种 shape：
1. **Standalone**：`{name, defaultPose, joints[], links[]}`——完整运动学定义
2. **Composition**：`{name, base, modifications[].AttachBot{...}}`——组合模式，引用 base bot + 通过 AttachBot 挂子 bot

这是 SuperDex 的**组合 API**（AttachBot），本质上就是 URDF/xacro `<include>` 的 JSON 等价物——但**更清晰**，因为是显式的引用图。

### 8.3 实现：`scripts/ingest_superdex.py`

单文件 Python 脚本，4 个模式：
- `--apply`：合并到 `api/entities.json`（写 backup 到 `.bak.<ts>`）
- `--dump DIR`：把原始 bot JSON 落到本地缓存
- `--from-cache DIR`：跳过网络，从缓存读
- `--dump-entities FILE`：sidecar entities JSON

**关键映射**（`.superdex_bot` → RoboParts entity schema）：
- `name` → `id`（slugify）+ `name`/`name_en`
- `joints[]` type ∉ {Hard, Fixed, Static} → DOF count
- `links[].mass` sum → `link_mass_kg_total`
- 路径 `assets/bots/arms/fr3/` → manufacturer="Franka Emika", category="platforms"
- 路径 `assets/bots/hands/allegro_v5/` → Wonik Robotics, 17-DOF
- 路径 `assets/bots/hands/wuji_hand2_beta1/` → AgiBot, 21-DOF

**Mechanical interface 声明**（从 upstream vendor datasheet 交叉引用）：
- FR3 / FR3 v2 → ISO 9409-1-50-4-M6（6×M6，Ø50mm BCD）
- Robotiq 2F-85 → ISO 9409-1-50-4-M6 / 40-4-M6 / 31.5-4-M5（3 种耦合件）
- Allegro V5 → 专有 flange（Ø52mm 4×M5）
- OpenArm V20 → 专有 flange（Ø39mm 3×M4）
- DG5F / Wuji / Oculus XR → `not_declared`（无公开 datasheet）
- Composition bots（如 FR3+DG5F）→ `n_a`（封闭系统，无外部 flange）
