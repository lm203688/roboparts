## 国际资源线（非竞赛）补充核查 09-03（用户追问"竞赛之外还有什么资源"）
除竞赛外，匹配 RoboParts（中国主体/不出国/零成本/Cloudflare栈/无GPU）的可行方向分三层：
- **T1 干净匹配、栈已用、线上申、无出差**：① Cloudflare for Startups（$5K bootstrap 档，1年免费Pro+Workers/R2/Vectorize credits，只需成立<5年+活站点+企业邮箱，无伙伴要求）；② GitHub for Startups（20席Enterprise+$10K credits+Advanced Security+Actions+Copilot，但我们是 bootstrap 无融资→需 GH 伙伴 referral 才稳，否则可能拒）。
- **T2 价值最高但需战略决策（开源）**：NLnet / NGI Zero（€5K–€50K 真金、全球可申含个人、无出差、滚动开申；**但须把成果以 OSS 许可发布**。2026 下一轮 9/3 已开申、11/3 截止→这是最大一笔"无出差实钱"，前提是愿开源兼容引擎/数据集）。
- **T3 弱匹配/条件强**：Hugging Face for Startups（须 ML-native，我们非；且有 Xet 中国网络问题）；Supabase/MongoDB/Pinecone 等 devtool perks（栈不匹配，暂不需要）。
- **中国本地通道**：中小企业国际市场开拓资金（上海 2026 窗口 8/31 刚关；各省自定）。须**进出口经营权+实际出境展/认证/专利**才报销 50–70%→RoboParts 纯 Web 平台无实物出口，当前低匹配；仅当未来做实体零部件出海才适用。
- 结论：竞赛放弃后最该做的是 **Cloudflare+GitHub 两件套**（栈已用、零成本、无出差）；NLnet 是天花板但卡在"是否开源"这个决策上。Hugging Face/中国出海补贴暂不入。

## Cloudflare + GitHub 两件套最终评估（用户追问"是否实际意义+到期是否付费"）
- **Cloudflare for Startups**：到期机制=最长1年或用光额度先到为准；条款"到期 Cloudflare 向存档卡扣费，**但 Enterprise 域未转付费则自动回 Free 档**"。RoboParts 是 Cloudflare Pages 静态站本就免费，不用计量付费产品→1年后自动回 Free、**不强制付费**。但价值极边缘（无 Workers AI/R2 负载），属"白拿没用"。→ **不申**（与"补贴意义不大"一致）。
- **GitHub for Startups**：① 硬门槛"需 GH 伙伴 referral **且** 外部融资 Series B 前"→我们是 bootstrap 无融资、无伙伴→**基本不达标**；② 即便达标，12个月后 Copilot(~$10–19/席/月)+Advanced Security(含 Enterprise ~$21/席+安全附加)转标准付费，10人团队约$580+/月=到期强制付费。→ **双重原因不申**。
- **结论：两件套都跳过**，精力不花在"虚补贴"上。
