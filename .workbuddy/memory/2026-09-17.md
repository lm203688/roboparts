## 落地：PPS 借鉴残差向量 + SO-101 GAP-G1 参考登记（commit e15daf8 + 漂移 e4bc0bc）

### 1. `api/derived_features.json` — residual 字段（PPS 哲学落地）

PPS 原文是「冻结 base 权重 + 两个轻量 proxy 之差 = 任务引导残差」；搬到 RoboParts 判定层：**base = ISO 9409-1 梯级冻结不动，只量化厂商声明与梯级的几何差向量**——这就是「转接盘的最小几何修正量」。

现产物 9 标号的 residual 分布：4 none + 1 thread-only (M5→M6) + 2 bolt+thread + 1 pcd+thread + 1 bolt+pcd+thread。thread 偏差 5 条，孔数偏差幅度 [0, 2, 4]。

**关键约束（`residual_scope_note` 明文）**：residual 只描述几何差，不裁决「能否互装」——判定权仍在 `build_negative_compat.py`。否则会出现「推导层说能装 / 判定层说不能装」的对外矛盾（这违反查表/裁决分离的既有约定）。

### 2. `neurorobotics/source.json` — 新增 `reference_robots` 数组

登记 `ROBOT-SO-101` 作为 GAP-G1（开放躯体标准件生态）的参考实现：6-DOF / 250g / 250mm / $300 自建 / Feetech STS3215。内嵌 `WM-DREAMZERO-SO101`：Vizuara AI Lab / Apache 2.0 / 217 MB LoRA / 24 步 action chunk / 11.9° zero-shot RMSE / 715 episodes。

**独立铁律（`validate_reference_robots()` 硬约束）**：
- `independence.no_weights_downloaded / no_source_shared / no_reverse_dependency` 三布尔必须 `true`
- 只登记存在性 + 许可 + 关键参数 + 兼容关系，不下载权重、不 clone 仓库、不读 KV/DB
- `integration_mode` 明文字段（"public API + 本表登记；不 clone 仓库、不读 KV/DB"）

RoboParts 对 SO-101 生态的实际价值：其夹爪端 `iso_9409_1_compatible: false`，需要 RoboParts 侧提供转接盘才能挂上标准法兰——这是把 $300 平台接入 ISO 9409-1 兼容宇宙的必经路径。

### 3. `regression.py` — L1.97 独立闸门（+257 行）

### 关键坑（记入 memory）

- **check() 签名陷阱**：`regression.py` 的 `check(cond, msg)` 原本只接 2 参，我写 L1.97 时误以为有 hint 第三参，第一次跑直接炸 `TypeError: check() takes 2 positional arguments but 3 were given`。修 `check(cond, msg, hint=None)` 兼容旧调用点，失败时附注 `｜hint`。教训：读旧代码前别臆造签名。
