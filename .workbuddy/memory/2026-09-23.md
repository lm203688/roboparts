## 深度论证 + 开源技术提升 + 拍板建议（第二轮）

### 已产出
- **深度文档**：`docs/direction-change-deep-dive-20260923.md`（多角度压力测试 + 开源建议 + 拍板表）

### 三个改变结论的联网核实发现（2026-09-23）
1. **GAP-G2 有直接先例**：`sepahead/NCP`（Neuro-Cybernetic Protocol v0.8.0，Rust+TS+Py，Zenoh 上规范化 JSON 契约，带 provenance）已做神经仿真器↔机器人契约 ⇒「没人做神经↔躯体契约」不成立，RoboParts 必须重新定位。
2. **学术界已命名该缺口**：PMC8866429《Embodied neuromorphic intelligence》原文指出脉冲↔经典电机控制器的系统级接口问题 ⇒ GAP-G2 的同行评审级佐证（可写进 data paper）。
3. **两方向有现成开源骨架**：方向一=Croissant 1.1（MLCommons，W3C PROV-O，700K 数据集，TF/PyTorch/HF/Kaggle 原生加载，有 MCP 集成）；方向三=LeRobot 0.6.1 + SmolVLA（4.5 亿参数 Apache-2.0，消费级 GPU ~2 万步微调，LIBERO 87.3%）。

### 竞品/生态全景（核实）
- 脑层：AI² Robotics NeuroVLA（2026-06 智源大会，AlphaBrain 开源，皮层/小脑/脊髓三层）、NeuroVLA 论文 arcxiv 2601.14628（真机 0.4W、反射<20ms）、Waterloo SNN 人形控制器（Nengo+Isaac Sim co-sim）
- 仿真平台：NRP（EPFL/fortiss，Human Brain Project 开源）
- 运行时协议：sepahead/NCP；BCI：ROS-Neuro
- 结论：**无人做"零件级兼容 registry"** —— RoboParts 切口独有但需绑定判定引擎+溯源才有壁垒

### 关键定位修正（必须同步）

### 已产出

### 核心结论
- **新定位**：RoboParts = 具身系统的**类型系统 + 组合演算 + 溯源层**（不是零件数据库）
- **方向一（学术验证）→ 放弃作为方向**，降级为 Phase A 副产品（零创新，天花板低）
- **方向二 → 升维为 D5 具身组合演算**（compose(brain,body)->Result|TypeError）
- **方向三 → 升维为 D4 形态-控制协同设计底座**
- **新增 D6 具身全链路溯源**（最易起步，flybrain PROV 现成）；D7 仿真生成并入 D4

### 新方向的前沿锚点（联网核实 2026-09）
- **D4 协同设计**：arXiv 2603.19582（GNN/GAT 形态图，"graph-structured policies = 形态与控制接口"）、BRIDGE arXiv 2609.03497（开源人形，对标 Toddlerbot）、AdaControl arXiv 2608.23100、Cambridge《Co-design is powerful and not free》
- **D5 形式化组合**：ARIA Safeguarded AI（范畴论 + AI 安全，Quanta 2026-03）、CSLib（Lean 组合式验证）、LIFR/VERIFAI2026（契约合成）
- **D6 溯源**：Croissant 1.1 采纳 W3C PROV-O（700K 数据集）、flybrain 已用 PROV-JSON 70/70、EU AI Act 合规刚需
- **D7 仿真生成**：Sleem45 CAD→URDF+Gazebo 自动验证、text-to-cad（11K stars，NL→URDF/SDF/DFM）⇒ 差异化弱，并入 D4

### 关键技术洞察
- **前沿用图做形态表示，但缺"标准化 + 已校验兼容"的零件图** ⇒ RoboParts registry 正是这个底座（协同设计搜索空间被合法剪枝）
