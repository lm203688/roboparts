## 一、agent.json 版本漂移修复（v1.1.0 → v1.1.1）

### 症状
- `.well-known/agent.json` 一直显示 `"version": "1.1.0"`
- `server.json` 已经是 `"version": "1.1.1"`（Registry 已发布）

### 根因
`scripts/gen_skills_manifest.mjs` 第 220 行硬编码 `version: '1.1.0'`，没有引用真相源。

### 修法
```javascript
const SERVER = JSON.parse(fs.readFileSync(path.join(ROOT, 'server.json'), 'utf8'));
const VERSION = SERVER.version || META.version || '0.0.0';
// ...
version: VERSION,  // 替换 '1.1.0'
```

- `python scripts/gen_public_manifests.py` → 数字现算 852/20/11/v1.1.1

## 二、LobeHub Marketplace 工具段刷新（8 → 11）

### 症状
`lhm.plugin.json` 的 `tools` 段是上一次 `plugin init` 时的旧快照（8 个含已废弃的
`dialects_list` / `dialects_evaluate` / `export_bom`）。当前 MCP 实际有 11 个工具，
但 LobeHub 展示的还是旧工具集。

### 关键突破：M2M 认证绕过 user token 过期

之前记忆说"LobeHub 需 user login（OAuth2 PKCE，需浏览器）"。**这是错的**。
`lhm auth refresh` 报 "No credentials found" 是因为 user credentials 与 M2M
credentials 是**两条独立路径**：

```bash
# 1) 注册 M2M 客户端（30 秒，无浏览器）
npx -y @lobehub/market-cli register \
  --name roboparts-publisher \
  --description "RoboParts marketplace CLI publisher" \
  --source claude-code
# → Client Id: cli_W2QMVYAcpwgkXKySvaEXClPK3qAZ8CCS
#   落 ~/.lobehub-market/credentials.json

# 2) 刷新 M2M token（1 小时有效）
npx -y @lobehub/market-cli auth refresh
# → Access Token: eyJhbGciOi...

# 3) 验证身份
npx -y @lobehub/market-cli auth status
# → M2M Authentication: authenticated
# → User Authentication: token expired（忽略，M2M 已足够）
```

**M2M 拥有完整的 plugin list / plugin init / plugin update 权限**——之前的 user OAuth 只是历史遗留流程。以后所有 LobeHub 发布都走 M2M。

### 完整流程
```bash
# 1) M2M 登录（已配置，token 自动从 credentials.json 读）
npx -y @lobehub/market-cli auth refresh

# 2) 从线上端点重新内省 tools（--url 比 --stdio 更真实，走的就是线上代码）
npx -y @lobehub/market-cli plugin init --force \
    --url https://roboparts.cc/mcp \
    --dir .
# → Discovered 11 tool(s), 1 resource(s)

# 3) 刷回 owner 声明（覆盖 init 清空的部分）
python scripts/gen_lhm_manifest.py
# → identifier=lm203688-roboparts｜version=1.1.1｜tools=11｜852/20

# 4) 原地合并到现有版本（不新增版本号）
npx -y @lobehub/market-cli plugin update --dir .
# → ✓ Updated lm203688-roboparts@1.1.1 (merged into the existing version)

# 5) 校验
npx -y @lobehub/market-cli plugin list
# → lm203688-roboparts｜1.1.1｜published｜claimed=yes
```
