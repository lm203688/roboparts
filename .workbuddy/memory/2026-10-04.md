## 第二段：共装前沿——`composed=0` 是关系类型错配（68 项闸门）

### 核心发现
之前把 `composed=0` 当失败叙事。本轮用三层分解证明它**很可能是语义真相**：

| 层 | 定义 | 实测 |
|---|---|---|
| L1 | 跨角色（signal 必要条件 OUTPUT×INPUT） | 28,310 对 / 393 节点 |
| L2 | L1 ∩ mechanical 可判定 | **63 对 / 16 节点** |
| L3 | L2 ∩ signal ✓ ∩ electrical ✓ | **0 对** ← composed |

L2 的 63 对**机械 63/63、信号 63/63 全通过**，唯一阻点 electrical
判的是「两器件能否**互插**」。

而这 16 个节点全是 **cobot EOAT**（夹爪/执行器 + 六轴力/力矩传感器），
共享同一 ISO 9409-1-A50-4-M6 法兰，**各自占机器人侧的一个电气端口**。
它们的关系是**共装（co-mount）**而非点对点直连（peer-to-peer）。

**实测证据**：两侧均取证的 18 对里，判出结果的 **13 对全部 incompatible、
0 compatible**（另 5 对因几何不可比判 unknown）。

**结论（强假说，非定理）**：补电气声明**很可能**不会让 composed>0。
真正的工程问题「这台机器人能否同时装夹爪 A 和传感器 B」当前模型答不了
——不是缺数据，是模型只有 peer-to-peer 一种关系。

## 第三段：MUSE / muselsl 接入裁决（不做数据接入）

### 结论：SDK 零加持，不做接入；但它是一件有价值的「证伪工具」

**事实核实**：`muselsl` = `rindieeagle/muse-lsl`，**BSD-3-Clause**，
v2.3.1（2024-06-03），兼容 Muse 2 / S / 2016，**Linux 官方支持**
（默认 bleak 后端，**无需 dongle**）。市场上同名 fork 众多
（digital-cinema-arts / andrewjaykeller / jnaulty / VT 等均为 fork），
**只有这一条在维护**——引用时必须指明，否则会引到 2016 年死代码。

Muse 2016 规格：BT 4.0 BTLE · 256 Hz / 12-bit · 电极 TP9/AF7/AF8/TP10（干电极）·
参考 FPz (CMS/DRL) · 2 mV p-p · 三轴加速度计 52 Hz/16-bit · 60 g。

**三层分开答**：
- (a) Linux 上跑 SDK？**能，但不是本项目的事**（用户侧采集工具）
- (b) 录进 parts registry？**不该**。MUSE 无法兰/无 ISO 9409-1/无机器人侧电气端口
  ⇒ MDV = 0；而实体数是本站核心对外数字 ⇒ **为无效数据放大核心指标 = 自我注水**
- (c) 闭合 provenance 链？**不能，schema 表达力不够**

**方向闸门**：Q1 ❌（`pip install muselsl` 即可，通用能力）/
Q2 ⚠️（问题是真的，但 BCI 社区已有 OpenBCI/BrainFlow/LSL，我们没先占）/
Q3 ❌（采集工具，离「让组合可校验」远）⇒ **三问两否，丢弃**。

另：MUSE 塞进 `neuron` 层是**语义错配**——该层定义为连接组
（connectome，count=5），MUSE 给的是头皮电生理时间序列。与共装错配**同型**。

### ★ 唯一实质发现：信号轴有结构上限（已量化并登记）

拿 MUSE 2016 逐字段试写 `neurorobotics/signal_interface.schema.json`：
```
controller: required=['connectome_ref','neuron_model'] addProps=false
  ❌ channels[]/device/reference/sampling_hz/transport 五个字段全越界
  ❌ 且缺必填 connectome_ref
mappings.output: controller_population 是 string 而非数组
```

⇒ **schema 只能表达离散 1:1 映射，无法表达连续多通道生理信号。**
这个上限早写在 `SIG_PORT_CAVEAT` 里，但**从未被量化到「差哪几个字段」**。
MUSE 给出的量化：**差 5 个字段 + populations 需从 string 变 array**。

### ★★ 判据固化（本轮最可复用的产出）
