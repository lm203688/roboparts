数据贡献

补一条带出处的机械接口声明，比重构算法有用得多。

当前缺口（现算，非手写）： 机械互换维度「能不能拧上去」声明率 75 / 489。 其余条目如实标注 not_declared——不猜、不填 0 假装有数据。 这不是"我们还没抓到"，是厂商公开资料里确实没写， 所以我们把缺口公开登记出来，而不是用估算值把它盖住。

一、三条合法通道（只有这三条）

通道做法产出
厂商 datasheet从厂商官网 / 官方手册读出孔位尺寸，附出处链接可升 declared
ISO 9409-1 查表标准梯级已知（A40/A50/A63/A80/A100/A160/A250），但厂商常偏离，须逐型核对可升 declared（带厂商出处）
用户提交带出处贴出你手上实机的尺寸 + 出处（手册页 / 官方图纸 / 官网配置器）至少 partial

反例（不接受的贡献）：凭标号外推、凭同系列推测、凭"应该差不多"、无出处的转述。 我们宁可留着 not_declared，也不猜——这份数据的唯一价值就是每条都能被核实到源头。

二、最快的一条路：粘贴规格书文本

把厂商手册里描述法兰的那一段直接粘进来。这里是确定性正则提取，不调用任何大模型—— 因此它不会"编"出一个孔位。产出永远是 partial（有线索但未经人工核对）， 升 declared 必须由人拿厂商官域出处逐字核对。

三、提交到仓库

  • 补机械接口声明 —— 不必会写 JSON，贴出处链接即可
  • 报数据错误
  • 详细规矩与最小可核验格式：CONTRIBUTING.md
  • 零件实体权威格式规范（字段表 + 可复制模板 + 闸门清单）：docs/part-annotation-spec.md

四、为什么我们敢公开缺口

RoboParts 不生产、不销售、不代理任何零部件，因此没有把选型结果导向自家产品的动机。 卖家不适合同时当裁判——这是关节厂商自建选型器无法复制的一条差异。 所以我们能公开说「这一条我们查不到」，而不是把它填成 0 让它看起来完整。
