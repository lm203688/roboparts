# RoboParts 法兰转接件生成器（开源）

> 把**不兼容的机器人法兰**变成**兼容**。

当机器人腕部法兰（侧 A）与工具 / 末端执行器法兰（侧 B）的螺栓节圆、孔数、螺纹不一致时，本工具自动生成一块可 3D 打印的转接板，让你把两端连起来。

这是 [RoboParts](https://roboparts.cc)「兼容无忧」从**判定**走向**解决**的一步：不仅告诉你"拼不拼得上"，还直接给你能打印的零件。

## 在线版（零安装，推荐）

🌐 **https://roboparts.cc/adapter-generator**

- 选两侧 ISO 9409-1 法兰（A50/A80/A100/A160）或自定义参数
- 浏览器内实时 3D 预览（three.js，无需后端）
- 一键下载 **STL**（直接 3D 打印）或 **OpenSCAD 源文件**（免费桌面端二次编辑）
- 生成的配置可**分享链接**复现，并支持 X / Reddit / Hacker News / 知乎 一键分发

## 命令行版（高精度 STEP，CadQuery）

适合要进 CAD（SolidWorks / FreeCAD / Fusion）做二次设计的场景，输出真实 BREP 实体而非三角面片。

```bash
pip install cadquery
python gen_adapter.py --a-preset A50 --b-preset A80 --thick 10 --bore 20
```

参数（两侧各一套，可被预设 + 显式覆盖）：

| 参数 | 含义 |
|---|---|
| `--a-preset` / `--b-preset` | ISO 9409-1 标准预设 A50/A80/A100/A160 |
| `--a-pcd` / `--b-pcd` | 螺栓节圆直径 PCD (mm) |
| `--a-holes` / `--b-holes` | 螺栓孔数量 |
| `--a-thread` / `--b-thread` | 螺纹规格（M6/M8/M10，用于推导过孔间隙） |
| `--a-pins` / `--b-pins` | 定位销孔数量（通常 0 或 2） |
| `--a-pin-d` / `--b-pin-d` | 定位销孔直径 (mm) |
| `--a-pin-pcd` / `--b-pin-pcd` | 定位销节圆直径 (mm，直径口径，非半径) |
| `--thick` | 板厚 (mm) |
| `--bore` | 中心通孔直径 (mm) |
| `--out-dir` | 输出目录 |
| `--strict` | 几何告警（干涉/边距不足）升级为错误，不产出 |

导出 `flange-adapter_A50-4-M6__A80-6-M8.step` 与 `.stl`。脚本会主动校验**孔位干涉**与**外缘壁厚**并告警（可用 `--strict` 拒绝出图）。

### 命名规则说明

- **标号格式**：`ISO9409-1-A{PCD}-{孔数}-{螺纹}`，如 `ISO9409-1-A50-4-M6`
- **PCD 含义**：螺栓节圆直径（Bolt Circle Diameter），非 ISO 外径 D
- **定位销**：标准梯级（A40/A50/A80）有定位销孔，非标准梯级通常无
- **canonical 标记**：A40/A50/A63/A80/A100/A160 为 ISO 标准梯级，其余为厂商偏离支

### 法兰互换规则

**直接互换条件**（三项全满足）：
1. 节圆直径 PCD 相同
2. 螺栓孔数相同  
3. 螺纹规格相同

**转接板必要条件**（任一不满足）：
- PCD 不同
- 孔数不同
- 螺纹不同（需换对应规格螺栓）

> ℹ️ 即使标号相同（如都是 A100），不同厂商的几何细节（法兰总厚、中心通孔、螺纹深度）可能不同，转接板设计仍需查原厂手册确认最大允许旋入深度。

## 材料参数与公差边界

### 推荐材料

| 材料 | 适用场景 | 强度等级 | 打印工艺 | 备注 |
|---|---|---|---|---|
| **PA12 (尼龙12)** | 工业应用 | ≥50 MPa | SLS/FDM | 耐油、韧性好，推荐首选 |
| **ABS** | 一般应用 | 40 MPa | FDM | 成本低，但耐油性较差 |
| **PETG** | 环境敏感 | 55 MPa | FDM | 强度高，但需干燥处理 |
| **AlSi10Mg** | 高负载 | 350 MPa | SLM/DMLS | 金属打印，成本高 |

### 公差边界

| 项目 | 最小值 | 推荐值 | 备注 |
|---|---|---|---|
| **板厚** | 4 mm | 8-12 mm | <4mm 刚度不足，>20mm 增加重量 |
| **外缘余量** | 2 mm | 18 mm (默认) | 确保螺栓孔不切到板边 |
| **孔间壁厚** | 1.5 mm | ≥3 mm | 避免应力集中 |
| **定位销配合** | g6 过渡配合 | H7/g6 | 严禁过盈硬敲 |
| **表面粗糙度** | Ra 3.2 | Ra 1.6 | 配合面需光滑 |

### 可打印性限制

- **最小特征尺寸**：≥0.5 mm（FDM），≥0.1 mm（SLS）
- **悬挑角度**：≤45°（超过需添加支撑）
- **填充密度**：建议 20-30%（承重件 40-60%）
- **后处理**：去除支撑、打磨配合面、必要时阳极氧化（金属件）

## 装配安全红线（来自 ISO 9409-1 法兰规范）

1. 螺栓**不得过长**——超长会顶破腕部油封导致减速器漏油，装机前查原厂允许旋入深度。
2. 螺栓强度等级按原厂（如 ABB 强制 12.9 级），禁用不锈钢 / 低等级防咬死或松动。
3. 定位销用 g6 过渡配合，严禁过盈硬敲损伤销孔。
4. 本工具产物为**几何转接建议**，不构成认证，量产前请样机实测。

## 螺栓物料清单（BOM）

本工具可自动生成配套螺栓清单：

```bash
python gen_adapter.py --a-preset A50 --b-preset A80 --thick 10 --bore 20 --bom
```

输出内容：
- 螺栓规格（如 M6×20）
- 数量（每侧各几颗）
- 最小长度（板厚 + 1.2×d，ISO 262 常用下限）
- 标准件型号（来自 step.parts 库存）
- 采购链接（如适用）

> ⚠️ **诚实边界**：螺栓长度按板厚 + 旋合现算，未计垫圈、被连接件孔深与倒角；板厚由调用方给定，本工具不判断其强度是否足够。

## 设计最佳实践

### 转接板设计原则

1. **优先使用标准预设**：除非特殊需求，优先选择 A50/A80/A100 等标准法兰
2. **板厚选择**：
   - 轻负载（<5kg）：6-8mm
   - 中负载（5-20kg）：10-12mm
   - 重负载（>20kg）：15-20mm
3. **中心通孔**：根据走线/走气需求设置，最小 Ø20mm
4. **沉孔设计**：建议使用沉孔（--cbore-depth 6-8mm），避免螺栓头干涉

### 常见问题解决

| 问题 | 现象 | 解决方案 |
|---|---|---|
| **孔位干涉** | 两法兰孔圈重叠 | 增大 --outer-margin 或旋转一侧法兰 |
| **壁厚不足** | 螺栓孔距板边 <2mm | 增大 --outer-margin 或减小 --bore |
| **定位销干涉** | 销孔与螺栓孔重叠 | 调整 --a-pin-pcd/--b-pin-pcd 或改用无销设计 |
| **刚性不足** | 转接板变形 | 增加板厚、添加加强筋、改用更高强度材料 |

### 质量控制

1. **打印后检查**：
   - 测量关键尺寸（PCD、孔径、板厚）
   - 检查表面质量（无分层、无气泡）
   - 进行破坏性测试（可选）

2. **装配前验证**：
   - 用螺栓试装（不拧紧）检查孔位匹配
   - 检查定位销配合松紧度
   - 确认中心通孔无堵塞
