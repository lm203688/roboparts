## 结论先行

**赛道不对，不建议参加。** 而且不是"勉强能挂上"的问题——它有一条硬约束，让 RoboParts 要么放弃参赛、要么放弃自己的技术栈。

## 二、五条硬不匹配（按严重度）

### 1. 作品必须在百度千帆平台上开发 —— 这是决定性的
首届各高校通知（长安大学、华中科技大学、河北经贸大学、中国技术经济学会官网）口径一致：队长须实名注册**百度智能云千帆平台**，账号 ID 回填大赛平台获取 token 与组队码；"参赛团队可在竞赛期间免费使用百度大模型应用平台"，作品是"在指定的平台开发 AI 智能体"。

RoboParts 是自建栈（Cloudflare Pages/Workers + 自有兼容引擎 + MCP 工具面 + ECS 推理网关）。要把参赛作品做进千帆，只有两条路：
- **迁过去** → 为一个赛重建一遍，且丢掉 MCP/自有数据层这些真正的差异化；
- **另做一个与 RoboParts 无关的千帆 Demo** → 对主项目零价值，纯粹消耗两周。

两条都不划算。

### 2. 总决赛必须到现场（12/18–12/20 现场答辩）
与用户"需要到现场就算了"直接冲突。不到现场 = 走不到终评 = 拿不到任何一档终奖。

### 3. 六大命题领域里没有机器人
唯一的擦边点是"制造 — 供应链优化"。RoboParts 是机器人零部件的选型/兼容判定层，要塞进"制造-供应链"需要把叙事扭曲一次；而评审的场景是经济学/管理学问题（首届官方表述："以经济学、管理学及其他领域作为应用场景"），不是工程数据层。

### 4. 受众错配
评委席 = 技术经济学会专家 + 高校教师，背景是技术经济学/管理学。
用户要的是"让投资方或业内人士了解项目"——这个赛的评委既不是机器人业内，也不是投资人。上了台也触达不到目标人群。
另：奖项是"实习就业绿色通道 / 人才库举荐"，对已在运营自己项目的个人几乎无价值。

### 5. 身份与流程别扭
赛事基因是高校学生赛（校赛环节、指导老师、按学历分组）。第二届虽写"欢迎科研单位和企业人士参与"，但**报名时需选择参加校赛的高校**，社会/个人团队如何走校赛未明确；企业人士被归入研究生组与硕博同台。再叠加 100 元不退的报名费——违反项目的"零成本优先"。

## 三、连带结论：ROSCon CFP 也出局

昨天推荐的 ROSCon China 闪电演讲路径，官方 2025 站明确写着：
> "ROSCon China 2025 is an **in-person event only**; remote or online presentations cannot be accommodated."

**必须到场讲 ⇒ 与"不到现场"冲突 ⇒ 一并放弃。**
不再发邮件询问，也不再准备提案草稿。（若将来改变主意，2027 届可再看。）
