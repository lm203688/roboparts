## 1. 用户核心目标（原文）

> 打造机器人生态为核心，目标是让机器人变成人人可组装的产业；其他生态可在平台接入，形成配件标准化；机器人用户数据（一致性+保密性）通过平台保留——上一台直接上传，下一台直接下载植入，保持用户习惯等私密信息；平台已实现配件设计，若接入 3D 打印可直接平台下单→打印寄送→组装；可通过开源形式集中机器人小模型；与 FlyBrain（大脑）、世界模型（训练）相呼应。可分阶段实现，Chief 评估后修正。

## 3. 分阶段实现方案（阶段划分 + 每阶段目标 + 呼应关系）

> 设计原则：每阶段**独立可验证**，fail-closed 纪律不变（三态判定/诚实/可溯源）；不虚构"已实现"。
> 与 PROJECT_DIRECTIONS_V2 决策闸门兼容：每阶段动作需过三问（是否产出别人做不出的东西/是否定义新问题/是否更接近具身组合演算）。

### 阶段一：核心判定引擎加固（P0 收尾 + P1 高价值项）—— 现状基础

- **目标**：把"组合校验层"这一核心资产做扎实，成为生态接入的**可信底座**。
- **具体**：91 项 CI 闸门保持绿；P1 高价值项落地（论文数字更新 / adapter 5 源门 / JS↔Py 重放 / pipeline→production / 包锁提交 / regen_derived --check 接入 / 前端构建 / lint+format 进 CI）。
- **价值**：判定引擎可信 = 生态接入的前提（其他生态敢接入，是因为判定可验证、可溯源）。
- **呼应**：无（纯内部加固，为后续阶段提供底座）。
- **验收**：91 项闸门绿 + 0 真红 + 工作区 clean。

### 阶段二：生态接入协议 + 配件标准化扩展

- **目标**：定义"其他生态接入"的契约，让外部生态（FlyBrain/世界模型/第三方零件库）可声明接入，形成配件标准化。
- **具体**：
  - 定义**生态接入契约**（adapter 规范：数据模式 + 版本协商 + 校验入口），落地 adapter 5 源门（P1 已排期）。
  - 扩展**接口标准化**：跨生态标准锚定（ISO 22166-1 模块化框架 / GB/T 20255807-T-604 信息模型）+ 新增生态的映射表。
  - 提供**生态接入 SDK**（声明式：生态声明自己的零件/接口/标准，RoboParts 校验后入 registry）。
  - **装配 URDF 参考格式**（方法学参考/情报级，非生产依赖）：外部生态声明"装配"时，可参考 Multi-Agent-CAD 的装配 URDF 输出格式（多 agent text-to-CAD 生成装配，清华 IEI Lab，1071★）作为契约格式参考；不引入其 LLM 生成逻辑（非确定性/装配实验性，与 fail-closed/可复现性纪律冲突）。
- **价值**：生态接入不是"加数据"，是"加可信校验入口"——其他生态可接入且判定保持中立。
- **呼应**：FlyBrain（大脑）接入其"接口"（神经控制→机械接口），世界模型（训练）接入其"动作/环境"接口。
- **验收**：至少 1 个外部生态完成接入契约演示（声明+校验+入 registry）+ 闸门绿。

### 阶段三：用户数据保留 + 跨机移植（一致性 + 保密性）

- **目标**：让机器人用户数据（配置/习惯/私密信息）通过平台**可保留、可移植**——上一台直接上传，下一台直接下载植入。
- **具体**：
  - 实现**用户数据档案**（profile）：机器人配置（BOM/接口/校准）+ 用户习惯（操作偏好/动作习惯）+ 私密信息（加密存储）。
  - 实现**跨机移植**：导出档案（上传）→ 新机导入（下载植入），保证**一致性**（档案校验通过才植入）+ **保密性**（HTTPS/KV 加密/API-key 隔离，既有 §2.5 基础）。
  - 数据 schema + 版本协商（档案带版本，跨版本兼容策略明确）。
- **价值**：用户换机不丢习惯——这是"人人可组装"的关键体验（组装容易，换机更容易）。
- **呼应**：世界模型（训练）——用户习惯可训练（策略初始化）；FlyBrain（大脑）——用户行为档案可作为大脑接入的用户侧数据。
- **验收**：档案导出/导入端到端测试（一致性校验 + 加密存储验证）+ 闸门绿。

### 阶段四：3D 打印链路（设计 → 下单 → 打印 → 寄送 → 组装）

- **目标**：平台已实现配件设计，接入 3D 打印后**平台直接下单→打印寄送→组装**闭环。
- **具体**：
  - **设计 → 打印件**：把既有"可 3D 打印转接件"能力固化为**可下单的打印件规格**（STL/参数/材料/公差）。
  - **下单 → 寄送**：接入打印服务商 API（按需，不建厂）——订单提交/状态/寄送跟踪。
  - **组装指引**：打印件 + 既有 BOM → 组装步骤/扭矩/校准（用户可自助组装）。
  - **规格 → 几何方法学参考**（情报级，非生产依赖）：阶段四的"规格→几何"（自然语言/规格自动生成打印件几何）可参考 Multi-Agent-CAD 的 text-to-CAD 方法学（多 agent 生成 STEP/URDF/转接件，99.3% 单件基准、成本 $4.85/件 vs 人工 CAD $29.45/件）——作为未来可选路径吸收方法学，**不引入 LLM 生成依赖**（保持项目确定性/可复现性纪律；99.3% 为单一基准非泛化，装配 URDF 为实验性）。详见 `docs/coda-bench-standard-mapping-20261106.md`（能力对标报告）与情报融合评估 R1 结论。
- **价值**：从"设计工具"到"交付实物"——人人可组装从"能设计"变成"能拿到"。
- **呼应**：FlyBrain（大脑）——组装完成后的机器人可接大脑；世界模型（训练）——组装后可在仿真/训练环境验证。
- **验收**：下单→打印→寄送链路演示（至少 1 件转接件下单跟踪）+ 闸门绿。
- **边界**：不建厂/不囤库存（轻资产，服务商 API 对接）；打印件规格需诚实标注（材料/公差/可打印性边界）。

### 阶段五：开源小模型集中 + 生态闭环

- **目标**：以开源形式集中机器人小模型（VLA/世界模型/策略），与 FlyBrain/世界模型形成生态闭环。
- **具体**：
  - **小模型 registry**：集中开源机器人小模型（robot_ai_models 46 条现有基础 → 扩展为可下载/可校验的模型 registry）。
  - **模型 ↔ 硬件适配**：模型推理需求（部署硬件/接口）与配件（执行器/传感器）匹配——既有的"large-model industrialization"扩展。
  - **生态闭环**：模型（智）+ 硬件（体）+ 大脑（FlyBrain）+ 训练（世界模型）四方接口打通。
- **价值**：开源小模型集中 = 生态"可组合的大脑"——用户选模型像选配件一样。
- **呼应**：FlyBrain（大脑）——小模型可作为大脑的候选策略；世界模型（训练）——小模型可被训练/评估。
- **验收**：模型 registry 含可下载模型 + 至少 1 个模型-硬件适配演示 + 闸门绿。

### 阶段六：规模化（人人可组装的产业）—— 远期

- **目标**：让"机器人变成人人可组装的产业"——生态、标准化、数据移植、打印链路、小模型集中全部就绪后的规模化。
- **具体**：生态接入数量/打印件交付量/用户数据移植量/模型下载量作为规模化指标；分阶段扩展（先机器人爱好者社区 → 教育/科研 → 产业）。
- **价值**：从"工具"到"产业"的跨越——核心是让组装这件事**可验证、可复制、可交付**。
- **呼应**：全生态（FlyBrain/世界模型/配件厂商/打印服务商）规模化协同。
- **验收**：规模化指标基线 + 阶段性增长（不虚构目标值，按实际数据演进）。
