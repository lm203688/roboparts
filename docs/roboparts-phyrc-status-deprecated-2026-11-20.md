## 2. 放弃原因（四条，均为实测/文档依据）

1. **问题域不匹配**：RoboParts 是「零件能不能装」的**静态组合校验**层；PhyRC 是「策略能不能在仿真中穿衣服」的**动态学习/控制**任务。评估文档（11-07）四要素评估结论为「任务定位相关性**低**」——问题域、所需资产、输出物三项均为低相关。
2. **缺少必需资产**：PhyRC 要求物理仿真环境 + 策略训练。本项目 MuJoCo 引入评估结论为**不引入生产依赖**（`docs/mujoco-integration-evaluation-20261109.md`）；无 Isaac/PyBullet；46 个模型目录仅有元数据。核心目标六阶段不含仿真。
3. **提交链路从未走通**：2026 版提交包 2026-11-10 就绪后卡在「Awaiting Browser Tool Login」（需人工浏览器登录 phyrc.org），至 2026-11-20 共 10 天零推进、零提交。
4. **投入产出为负**：PhyRC 2027 无奖金（Cornell + KAIST 组织）；2026 版亦无奖金。放弃的成本为 0（无已投入的独占资产），继续投入需重建仿真栈，与阶段二/四优先项冲突。
