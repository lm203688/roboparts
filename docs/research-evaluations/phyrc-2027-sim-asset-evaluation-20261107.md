## 1. 与 RoboParts 定位的相关性

### 1.1 核心问题

RoboParts = **组合校验层**（组合形式化底座）：判定零件能否装配/共装/互换，输出三态结论（能/不能/不知道），生成可 3D 打印转接件。核心目标（用户 2026-11-06 定义）六阶段：核心判定引擎 / 生态接入+配件标准化 / 用户数据保留 / 3D 打印链路 / 开源小模型集中 / 规模化。

PhyRC = **仿真控制任务**（dressing in simulation）：训练策略（policy）在物理仿真环境中完成穿衣——这是**学习/控制**问题，不是**组合校验**问题。

### 1.2 相关性判断

| 维度 | RoboParts | PhyRC | 相关性 |
|---|---|---|---|
| 核心问题 | 组合/装配/互换判定（三态） | 仿真中学习穿衣策略 | **低**（不同问题域） |
| 输出 | 能/不能/不知道 + 转接件几何 | 仿真策略 + 分数 | 低 |
| 所需资产 | 实体目录/组合图/几何 | 仿真环境（MuJoCo/Isaac）+ 策略训练 | 低 |
| 用户场景 | 开源机器人构建者选型/装配 | 研究基准（dressing 是护理机器人方向） | 低 |
| 物理真实性 | 静态几何/接口（ISO 9409） | 动态物理仿真（接触/布料/形变） | 低 |

**结论：任务定位相关性低。** RoboParts 是"零件能不能装"的静态组合问题；PhyRC 是"策略能不能在仿真中穿衣服"的动态学习问题。两者共享"机器人"主题词，但问题域、所需资产、输出物均不同。

## 2. RoboParts 现有资产能否利用

### 2.1 现有资产（本次核实）

- **实体目录**：868 实体 / 20 大类 / 46 模型（robot_ai_models.json：VLA/策略模型 46 个，含 RT-2/Octo/OpenVLA/GR00T/SmolVLA 等，**但这是目录条目，非可运行模型**）
- **91 项 CI 闸门**（150 子项，本次 149 绿 + 1 真红 data.json 新鲜度）
- **几何/接口资产**：ISO 9409-1 法兰、co_mount 组合引擎、kinematics 校验、adapter 生成器（CadQuery→STEP+STL）、URDF 提取器、PCD/孔数校验
- **URDF/MJCF**：`scripts/sample.urdf`、`outputs/live_URDF-001.mjcf.xml`（**单件样例**，非完整机器人）、`functions/_urdf_lint.js`
- **仿真框架**：**无 MuJoCo/Isaac/PyBullet/Gymnasium/Pinocchio 依赖**（requirements.txt 仅 PyYAML/usd-core/jsonschema，无任何仿真框架）

### 2.2 能否利用

| 资产 | 能否用于 PhyRC | 说明 |
|---|---|---|
| 实体目录（868） | ❌ 低价值 | 静态零件目录，PhyRC 需要可动模型 + 服装形变，不是零件清单 |
| 46 模型目录 | ⚠️ 仅参考 | 是**目录条目**（元数据/规格），非可运行策略权重；且是"机器人学习模型"清单，PhyRC 是仿真任务 |
| ISO 9409 法兰/转接件 | ❌ 不相关 | 静态机械接口，穿衣仿真不需要法兰 |
| URDF 提取器 | ⚠️ 方法学参考 | URDF→关节运动学提取与 PhyRC 的机器人建模有部分交集（但 PhyRC 用官方仿真环境，自带模型） |
| MJCF 样例 | ⚠️ 单件 | 单件样例，非完整机器人，无法直接用于穿衣仿真 |
| 仿真框架 | ❌ 不具备 | **RoboParts 无 MuJoCo/Isaac 依赖**——要利用 PhyRC 需新增仿真框架依赖（超出当前定位） |

### 2.3 关键诚实边界

**RoboParts 不具备仿真框架（MuJoCo/Isaac/PyBullet 均未依赖）**。PhyRC 是仿真挑战，利用它需要引入仿真环境——这不是 RoboParts 当前能力，也超出"组合校验层"定位。若要做仿真，是新增能力（需单独立项），非"利用现有资产"。

## 3. 四要素评估

| 要素 | 评估 | 理由 |
|---|---|---|
| **价值** | 低 | PhyRC 是"仿真中学习穿衣策略"基准，与 RoboParts"组合校验+3D打印"定位不同问题域。最大价值是**方法学参考**：①物理仿真验证机械装配（如果未来做"装配仿真"——但当前无此能力）；②动态接触/形变建模思路（RoboParts 是静态几何，无动态需求）。作为"仿真资产参考"价值有限：RoboParts 不跑仿真，也无仿真依赖。 |
| **成本** | 低（仅评估） | 纯评估零成本。若实际利用：需引入 MuJoCo/Isaac 依赖 + 学习穿衣策略——这是**新增仿真能力**，成本高（框架安装/环境搭建/策略训练/基准复现），且超出当前定位。 |
| **风险** | 中 | ①**定位漂移**：RoboParts 是组合校验层，PhyRC 是策略学习——若纳入生产，会把项目从"静态机械校验"拉向"动态仿真学习"，弱化核心定位；②**依赖膨胀**：引入仿真框架（MuJoCo/Isaac）大幅增加依赖与 CI 负担；③**可复现性冲突**：仿真基准依赖随机训练，与 RoboParts"fail-closed/可复现"核心价值冲突（R1 已指出同类问题）；④**无奖金**：无直接收益。 |
| **定位契合** | 低 | 任务定位不匹配。RoboParts 六阶段中：阶段一核心判定引擎（静态组合）、阶段二生态接入（配件标准化）、阶段三用户数据、阶段四 3D 打印链路、阶段五开源小模型集中、阶段六规模化。PhyRC（穿衣仿真）与**任何一阶段都不直接对应**——最接近是阶段五"开源小模型集中"（但那是模型**目录**，非训练仿真策略），仍不匹配。 |

### 3.1 四要素结论

**纳入参考（情报级/方法学参考，非生产依赖）** —— 与 R1（Multi-Agent-CAD）同类处理：方法学参考可记录，不引入生产。

但**明确标注**：
- 不引入 MuJoCo/Isaac 仿真框架（RoboParts 无此能力，且超出定位）
- 不训练穿衣策略（非本领域）
- 不新增仿真依赖（保持 requirements.txt 三依赖现状）
- 最大价值=**认知边界**：了解"机器人仿真基准"在做什么，为未来若用户要"装配仿真验证"（阶段四 3D 打印链路的潜在延伸）留方法学注脚

## 4. 结论

**结论：纳入参考（方法学参考/情报级，非生产依赖）**，与 R1（Multi-Agent-CAD）同级处理。

- **相关性**：低（不同问题域：静态组合校验 vs 动态仿真学习）
- **现有资产利用**：低（868 实体/46 模型为目录条目，非可运行模型；无仿真框架依赖）
- **仿真框架**：RoboParts **不具备** MuJoCo/Isaac/PyBullet——要利用需新增能力（超出定位）
- **价值/成本/风险/定位**：低/低/中/低——作为方法学参考可记录，不引入生产
