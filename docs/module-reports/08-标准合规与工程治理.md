## 二、流程审计

### 2.1 流程是否合理

**这是全仓唯一「已经越到独立开发者项目水位之上」的板块。** 它不只做判定，还做**关于判定的判定**：

| 元层能力 | 实测证据 | 为什么稀有 |
|---|---|---|
| 变异评分（测试够不够） | 6 个变异体针对「三态守恒破坏 / 轴边际 / 证据指针 / 诚实边界 / 分母收缩」，杀死率 1.00 | 多数项目只有覆盖率，覆盖率会说谎 |
| 反模式档案（怎么错的） | AP-01「无价格冒充在预算内」、AP-05「接入路径断裂」、AP-10「mount_type 当身份键」、AP-12「truthy 判断压三态」 | 把事故变成**可复用规则 + 阴性测试** |
| 负结果档案（什么路不通） | NR-09「单一标量适应度做多目标进化」= **否决**；NR-10「桥接映射表代码化 S1」= **未启动** | 系统产出「此路不通」的可证结论 |
| 决策留痕（为什么这样定） | TDD-2026-01 用**四条硬指标**排除世界模型，并挂闸门守护 | 「不引入」也有依据且可被 CI 核对 |
| 自愈（怎么自己修） | 数字保鲜 / 部署漂移 自动修复 + 复测 + 上线，失败回滚 | 从「检测→写待办」升级为「检测→修复→复测」 |

> **判断**：流程**不仅合理，而且已经形成方法论**。这是 RoboParts 最不可复制的资产。

### 2.2 是否全面走通

| 子链路 | 状态 |
|---|---|
| 数据变更 → 闸门 → 拦截 | ✅ 通（49 项） |
| 事故 → 反模式规则 → 阴性测试 | ✅ 通（AP-01~AP-12） |
| 失败假设 → 负结果档案 → 改道 | ✅ 通（NR-01~NR-10） |
| 决策 → 留痕 → 闸门守护 | ✅ 通（TDD-2026-01 + 第 47 号闸门） |
| 数字过期 → 自愈 → 上线 | ✅ 通 |
| 部署漂移 → 自愈 → 回滚 | ✅ 通（逻辑） |
| **闸门 → 对外可见** | ✅ 已做（`llms.txt` 的「工程可信信号」段 + README §11） |
| **治理成果 → 外部引用** | ❌ **断**：无外部项目引用这套方法论 |
| **闸门成本控制** | ⚠️ **隐患**：49 项闸门 + 177 脚本的维护负担在单人项目上是**高风险** |

> **结论**：治理链路**全面走通**且对外可见；断点在「外部认可」与「维护负担」。

### 2.3 是否符合人类使用习惯

本板块的用户是**维护者自己**（+ 潜在贡献者）：

| 真实动作 | 本板块支持 | 契合度 |
|---|---|---|
| 「我改完怎么知道没搞坏」 | `ci_gate.py` 一键跑 49 项 | ✅ 极好 |
| 「我怎么知道测试够不够」 | 变异评分 | ✅ 好 |
| 「我上次为什么这么改」 | 反模式档案 + 决策留痕 | ✅ 极好 |
| 「哪条路试过不行」 | 负结果档案 | ✅ 极好 |
| **「新人怎么接手」** | 文档极全，但**总线因子=1** | ⚠️ 高门槛 |
| **「我想贡献但怕搞坏」** | 有 `CONTRIBUTING.md`，但门槛不低 | ⚠️ |

> **关键观察**：**这套治理体系是为「单人长期维护」优化的**——它极大地降低了「自己犯错的概率」，但没有降低「别人接手的门槛」。这是一个**有意的取舍**，但也是单点风险。

## 三、市场竞品与市场需求比较

### 3.1 竞品对照

| 竞品 | 定位 | 强项 | RoboParts 的差异 |
|---|---|---|---|
| **各国标/ISO 合规工具** | 合规检查 | 官方 | 只查「是否符合标准」，不查「自己说的是否为真」 |
| **开源项目的 CI 体系**（多数） | 测试 + lint | 通用 | 极少有**变异评分 + 反模式档案 + 负结果档案** |
| **AI 生成代码验证（2026 热点）** | 保证 AI 产出正确 | 主流关注 | 多数项目**没有真实事故记录**；RoboParts 有 |

> **生态位**：**这是 RoboParts 最被低估的资产**。2026 年「AI 生成代码/数据怎么保证正确」是巨大需求，而**多数团队没有一手事故案例**——RoboParts 有 12 条 AP + 10 条 NR + 完整治理史（`ops/results/_SUMMARY.md` 170+ 轮）。

### 3.2 市场需求实测

- 该板块**没有直接的商业需求**（没人买「治理方法论」），但有**学术与声誉需求**。
- 项目已把三个信号（变异评分 / 反模式 / 负结果）接入 `llms.txt` 的「工程可信信号」段——**这是正确的对外策略**。
- 但**无外部引用**：没有论文、没有其他项目采纳这套规则。

> **判断**：**这套方法论的价值远未被兑现**。它应该是一篇论文的核心，而不是 README 的一节。

## 六、诚实边界

1. **本板块是全仓最强资产，但也是全仓最大的单点风险**：177 脚本 + 49 闸门 + 完整治理史全部依赖单一维护者。
2. 变异评分杀死率 1.00 是**试点范围**（6 个变异体，主要针对 `compose_semantics.json`），不等于全仓测试强度。
3. `NR-10`（桥接映射代码化 S1）状态为「未启动」，说明四维报告的框架收敛建议**尚未落地**。
4. 标准映射不构成符合性声明（仓内无 ISO/GB 原文）。
