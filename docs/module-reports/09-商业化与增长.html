一、板块定位与边界

一句话：把「判定能力」变成可持续的收入与增长——但明确拒绝抽佣（一旦抽佣，判定就不再中立）。

三条子链路：

子链路 资产 实测状态
付费（积分制） 虎皮椒支付（api.xunhupay.com）+ Creem；套餐 starter ¥9/100 分、pro ¥29/500 分、lifetime ¥199/无限 ⚠️ 链路完整，零真实付费
积分账本 _lib/ledger.js（唯一入口）+ /api/credits/* ⚠️ 曾静默失效（见下）
增长 22 篇技术文库 + KPI 日报 + 社交自动发稿 + GEO/MCP 健康仪表盘 + 候补页 ⚠️ 内容产能强，转化弱

实测关键事实（重要）： - wrangler.toml 绑定 5 个 KV：USER_CREDITS / API_KEYS / SUPPLIERS / SUPPLIER_INQUIRIES / URDF_LIBRARY。 - USER_CREDIT_HISTORY 从未绑定——而账本代码曾依赖它。ledger.js 文件头如实记录：注册赠送 100 积分、真实付款到账、历史查询全部静默不写，把「账本从没记过」渲染成「你没有交易」。「在钱上撒谎」。 - 现已修复：账本回落至 USER_CREDITS 的 hist: 前缀，且立下两条硬规矩：「不可读 ≠ 空」、「不可读时汇总必须是 null 不能是 0」。

用户 真实诉求 本板块支持 契合度

三、市场竞品与市场需求比较

3.1 竞品对照

竞品 商业模式 RoboParts 的差异
TraceParts / GrabCAD 厂商付费上架 + 广告 RoboParts 不抽佣、不卖零件，靠 API 订阅
Octopart 广告 + 导流分成 RoboParts 明确拒绝导流分成（保中立）
数据 API 商（如各类工业数据） 订阅制 RoboParts 定价极低（¥9 起），更像「象征性收费」

生态位：RoboParts 的商业定位是「中立判定能力的 API 订阅」——不卖货、不抽佣、不导流。这个定位的难点是：中立性有价值，但「谁为中立性付费」不清楚。
