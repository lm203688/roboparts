二、流程审计

2.1 流程是否合理

这是全仓唯一「已经越到独立开发者项目水位之上」的板块。 它不只做判定，还做关于判定的判定：

元层能力 实测证据 为什么稀有
变异评分（测试够不够） 6 个变异体针对「三态守恒破坏 / 轴边际 / 证据指针 / 诚实边界 / 分母收缩」，杀死率 1.00 多数项目只有覆盖率，覆盖率会说谎
反模式档案（怎么错的） AP-01「无价格冒充在预算内」、AP-05「接入路径断裂」、AP-10「mount_type 当身份键」、AP-12「truthy 判断压三态」 把事故变成可复用规则 + 阴性测试
负结果档案（什么路不通） NR-09「单一标量适应度做多目标进化」= 否决；NR-10「桥接映射表代码化 S1」= 未启动 系统产出「此路不通」的可证结论
决策留痕（为什么这样定） TDD-2026-01 用四条硬指标排除世界模型，并挂闸门守护 「不引入」也有依据且可被 CI 核对
自愈（怎么自己修） 数字保鲜 / 部署漂移 自动修复 + 复测 + 上线，失败回滚 从「检测→写待办」升级为「检测→修复→复测」

判断：流程不仅合理，而且已经形成方法论。这是 RoboParts 最不可复制的资产。

本板块的用户是维护者自己（+ 潜在贡献者）：

真实动作 本板块支持 契合度

三、市场竞品与市场需求比较

3.1 竞品对照

竞品 定位 强项 RoboParts 的差异
各国标/ISO 合规工具 合规检查 官方 只查「是否符合标准」，不查「自己说的是否为真」
开源项目的 CI 体系（多数） 测试 + lint 通用 极少有变异评分 + 反模式档案 + 负结果档案
AI 生成代码验证（2026 热点） 保证 AI 产出正确 主流关注 多数项目没有真实事故记录；RoboParts 有

生态位：这是 RoboParts 最被低估的资产。2026 年「AI 生成代码/数据怎么保证正确」是巨大需求，而多数团队没有一手事故案例——RoboParts 有 12 条 AP + 10 条 NR + 完整治理史（ops/results/_SUMMARY.md 170+ 轮）。

3.2 市场需求实测

  • 该板块没有直接的商业需求（没人买「治理方法论」），但有学术与声誉需求。
  • 项目已把三个信号（变异评分 / 反模式 / 负结果）接入 llms.txt 的「工程可信信号」段——这是正确的对外策略。
  • 但无外部引用：没有论文、没有其他项目采纳这套规则。

判断：这套方法论的价值远未被兑现。它应该是一篇论文的核心，而不是 README 的一节。
