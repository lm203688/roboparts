📏 风险规则（每条规则 = 一个判定维度）

📡 Tier-C 低证据源
source_tier = "C"：数据来自二手汇总或间接渠道，未经一手厂商手册核验。占全库约 55%，最普遍的问题。
P0
📉 低置信度
confidence < 0.5：系统对这条数据的整体信心不足，多半是字段缺失或来源冲突。
P0
🚫 隔离项（quarantine）
quarantine = true：已知存在疑点（占位 ID / 无法核实的厂商 / 重复），已被隔离但仍可能漏进下游查询。
P1
💲 价格格式异常
price_range 含前导零（00-150）、N/A、无法解析等格式。这类条目"看着有价格"，但实际不可用。
P1
📊 价格跨度大
区间跨度 ≥ 100 倍（如 0-100、0-500），通常意味着数据不精确或来自多档产品合并。
P1
🔓 未隔离但有价
有 price_range 但 quarantine = false 且 source_tier = C：容易被下游当作"有明确价格"的条目采信。
P2
🏷️ Tier-A 但低价
source_tier = "A" + price_range 起点为 0：可能是开源/实验设备，也可能是"起价"写法，需人工复核。
P2
🔇 无价格字段
库内 约 74% 条目无 price_range（实测 767 条中 74.2%），无法做价格研判。这不是异常，而是**覆盖缺口** —— 数据工程优先项。

风险等级说明：P0 直接判定可疑，P1 需人工复核，P2 为可选关注。同一条目可命中多条规则。
