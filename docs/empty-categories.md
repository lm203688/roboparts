## 优先级排序（对齐 G-06 定向补数据）

审计 G-06 指出：**占库 25.6% 的 actuators 品类可判定数为 0**。
电气/信号轴判定需要 connectors + cables + power 三角，它们目前全 <5。

**顺序**：

1. **connectors / cables / power**（电气轴前置，1-2 周）
2. **integrated_joints**（一体化关节国标时间窗，2 周）
3. **pcb / controllers / structural**（补齐全，1 周）

## 数据面策略（当前不做，标注）

本轮**不主动隐藏**空品类，理由：
- 空品类本身就是"我们要建的方向"，隐藏会让用户误以为不需要
- 前端 `parts-viewer.html` 会按品类分组显示，用户能看到"这里只有 2 条"
- 补齐 ROI 排序是本文件的实际内容，让贡献者知道"往哪里投"

## 闸门策略

审计 G-12 建议加一个"空品类隐藏或登记"闸门。本轮**只加文档不加闸门**，理由：
- 数据侧还在补，闸门强制隐藏会挡住补齐进度
- 待补到 5 条以上的 7 个品类全变非空后，本文件删除

## 与其它缺口关联

- **G-02**（compose=0）：电气轴空是 compose 输出 0 的输入侧根因之一
- **G-06**（actuators 0 可判定）：actuators 依赖 connectors 做机械接口判定
- **G-13**（协议性能基准 27 条）：与 cables/power 一起是电气轴三角

三者本质是同一件事：**电气轴三角数据缺**。
