## 3. MINERVA — 基准 / 研究情报（小模型容量地板）

**一手来源**：`github.com/k1000dai/MINERVA`（Apache 2.0）；arXiv 2609.03715（2026-09）；HuggingFace `k1000dai/MINERVA`；humanoidintel.ai 解读。

**已核实事实**：
- MINERVA = **MIN**imal **E**fficient **R**obotic **V**ision-**A**ction policy，0.54M 参数紧凑操作策略，面向 LIBERO 40-task 闭环基准。
- 结果：4 套件平均 **95.75%**（L1 head），仅比 π0.5（4.1B）低 2.4 点，用 **7,700× 更少参数**；笔记本 CPU **5–9 ms/chunk**，无需 GPU。
- 容量地板：~1M 饱和，<0.25M 崩溃。
- 局限：task-ID 条件，**非通用 VLA**，不能执行未见指令；LIBERO-Plus 扰动降到 **46–56%**（光度鲁棒 ≈0）。
- 关键发现：LIBERO 指令条件主要选「记忆任务」（task-ID 置换探针降到近随机）→ 基准记忆动态；flow matching 相对 L1 回归无 detectable 优势。

**RoboParts 关联**：
- 支撑 RoboParts「零件级判定可用小模型」叙事：有界操作任务 0.54M 即够，呼应 RoboParts 轻量 Copilot 路线。
- LIBERO 饱和 + 鲁棒性差 → 研究空白信号（与 SwarmLabs 科研实体「研究空白」同源，但本次归 RoboParts 作基准情报）。

## 4. LIBERO — 基准情报（标准套件已饱和）

**一手来源**：百度百科 LIBERO 词条；paperswithcode LIBERO benchmark；CSDN LIBERO 详解；各模型榜单报道。

**已核实事实**：
- LIBERO：终身机器人学习基准，4 套件（Spatial / Object / Goal / Long）+ LIBERO-100（90+10），基于 RoboSuite / MuJoCo。
- SOTA 已饱和：LaST-R1 **99.9%**（1 条轨迹预热 + 在线 RL）、越疆 DobotWAM **99.25%**、π0.5 97.5、MINERVA **95.75% @0.54M**。
- 扩展 LIBERO-Plus（OpenMOSS，7 维扰动）暴露鲁棒性缺口：MINERVA 掉到 46–56%。

**对用户「libero 没难度」的核验结论**：
- ✅ 标准 LIBERO 四套件确已饱和（顶尖模型 >99%）→ 「没难度」在标准口径成立。
- ⚠️ 但鲁棒性扰动版（LIBERO-Plus）仍难（46–56%），真实硬件 / 光度偏移远未解决 → 「没难度」仅限标准基准，**非通用操作能力**。

**RoboParts 关联**：基准情报，佐证「基准驱动的规模 ≠ 部署必要规模」，支持 RoboParts 轻量判定路线。
