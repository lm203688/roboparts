## 3. 三项硬门槛评估

### 3.1 算力门槛：**不满足**

- **Isaac Sim 渲染/物理仿真需求**：高端 GPU（RTX 4090/A100）+ 多核 CPU + 大内存
- **RoboParts 现有算力**：仅 CI/CD 服务器（2 核 CPU + 8GB 内存），无 GPU 资源
- **结论**：算力缺口巨大，需额外投入

### 3.2 数据门槛：**不满足**

- **PhyRC 数据集许可**：需单独申请，无现成访问权限
- **RoboParts 数据现状**：机械零件兼容性数据（868 实体），无柔性物体/穿衣仿真数据
- **结论**：数据完全不匹配，需全新采集

### 3.3 合规门槛：**高风险**（合规专家核验，2026-11-09）

- **IP 归条款**："参与即把成果 IP 让渡给主办方"
- **风险等级**：**高**（从紧把握：条款涵盖既有资产=高，仅限竞赛新产出=中；鉴于 868 实体/46 模型目录让渡范围模糊，按"高"处理）
- **风险分析**：
  - **IP 范围**：算法模型、训练数据、改进方法、衍生成果
  - **对 RoboParts 影响**：若产出与机械校验相关的创新方法，可能被归类为"衍生成果"
  - **商业化影响**：限制了后续商业应用的可能性，成果归属权不确定
- **开源与既有 IP 冲突 3 点**（合规专家识别）：
  1. **第三方授权资产混入**：entities.json 引用第三方许可资产（如厂商规格/开源模型），一旦让渡可能连带让渡第三方权利
  2. **商业秘密（内部数据）**：api/ 数据含内部判定逻辑与未公开证据，让渡会泄露内部知识
  3. **共有 IP 分割**：与协作方/贡献者的共有 IP 无法单方让渡，需各方同意
- **合规动作清单**（若决定参与）：
  1. **IP 边界界定清单**：既有资产 vs 竞赛新成果分列，逐项标注权属
  2. **优先 Apache-2.0 含专利授权**：选用含专利授权条款的许可，避免专利陷阱
  3. **权属登记**：对核心资产预先登记权属，形成证据链
  4. **争取替代条款**：力争"参与者保留所有权、仅授予竞赛使用许可"替代自动让渡
- **核心提示**（合规专家）：若条款无法就**既有资产排除**且必须提交 868 实体/46 模型 → **建议不参与**，或以"仅竞赛新成果让渡"条件参与。
- **应对建议**：若参与，需明确界定 IP 范围，保护核心算法专利；当前判断按"高"风险，不参与实为最稳。
