# 增长渠道评估：外溢流量 & 竞赛曝光

日期：2026-09-09 · 评估人：飞轮（含不采纳项与理由）
结论先行：**两个方向机制都不假，但对现阶段的 RoboParts 都不是最优解。顺序错了。**

---

## 零、先说一个前提：做渠道之前必须先装量具

本轮之前，站上"有没有外部流量"这个问题**是答不出来的**，原因有三层（都已修复）：

| 断点 | 现象 | 修复 |
|---|---|---|
| 归因不聚合 | `register.js` 算出 `source/detail` 只写进单条用户记录，无计数键 ⇒ "古月居来几个人"要遍历全部用户键 | 补 `stat:via:<source>:<detail>` 聚合键 |
| 标记走 HTTP 头 | 渠道标记原只认 `x-roboparts-via` 头，浏览器点链接不带自定义头 ⇒ 社区发帖→点击→注册整条不可见 | 补 URL 参数 `?via=`（头优先、参数兜底） |
| 只有注册没有点击 | 无法区分"没人来"和"来了留不住" | middleware 补 `via:<ch>` 点击计数，与注册配成漏斗 |

现在可用：
```bash
python scripts/channel_report.py --link guyuehome   # 生成带标记的投放链接
python scripts/channel_report.py --days 7           # 看渠道漏斗（点击 / 注册 / 转化）
```

**注**：遥测读数是**下界**（分片读-改-写会互相覆盖），只能证明"至少有多少"，不能证明"只有这么多"。

## 一、"对接机器人需求平台，吃他们的外溢流量"——多数情况不成立

这个说法里藏着一个错误模型：**以为别人池子里的水会流过来**。按平台类型拆开看，结论完全不同：

### 类型 A：撮合型供应链平台 —— ❌ 不成立（是同赛道，不是上游）

已核实样本：**北京亦庄"机因工场"**（2026-07-30 ESCC 大会发布，北京市政府网/央视网/经济日报均有报道）。
它自己的模块就是**选型选件中心 + BOM 一站式选型 + 快速打样 + 共享工厂 + TURN-KEY 交钥匙平台**，首批入驻 20 余家（奥比中光、中大力德、珞石、地瓜等）。

- **它是竞品，不是流量源**：它做的事和 RoboParts 的选型层高度重合，不存在"把用户导给你"的动机；
- **它的流量根本不在公网**：线下撮合 + 园区企业定向对接，2 小时响应、48 小时交付，需求是**定向派单**，不会溢出到第三方网站；
- 唯一理论机会是"作为数据中立层被它集成"，但政府/园区平台几乎不可能链一个个人运营的小站 —— **概率极低，不值得投精力**。

### 类型 B：内容型开发者社区 —— ✅ 成立，但机制是"供稿"不是"对接"

已核实样本：**古月居**（ROS 机器人知识分享社区）——100 万+ 线上开发者、300+ 合作企业、400+ 高校；每年办 **ROSCon China**（2026 届：10 月 16–17 日，上海美的全球创新园区，设"产业对接 / 人才双选 / **开源项目路演**"板块与招商合作通道）。

- 这类社区**确实有真流量可外溢**，但获取方式是你产出内容（技术文章 / 开源项目 / 数据集），社区给你曝光 —— 不是谈个对接就能导流；
- 成本：时间（写稿）；金钱 0。

### 类型 C：被集成型（工具链 / 目录） —— ✅ 成立且最匹配定位，但是慢热长尾

已在 `docs/ecosystem-linking-20260908.md` 评估：LCSC/JLCPCB（制造闭环）、KiCad/atopile（AI-PCB 上游）、Octopart（MPN 批量回填，消解 connector 1.8% 覆盖缺口）、MCP 目录。

- 匹配度最高：RoboParts 是"判定/规格层"，天然是别人工具的输入；
- 但流量是长尾累积，不是冷启动爆发。

> **一句话**：能吃到的外溢只有"内容流量"和"被集成流量"两种，撮合型平台的采购需求不外溢。

## 二、竞赛曝光——机制真实，但对本项目的概率要分开看

**机制是真的**：评委席 = 行业专家 + 投资机构，确实是让业内人认识你的有效通道，且获奖有背书效应。

**但已核实的窗口，大部分已经关了**（今天是 2026-09-09）：

| 赛事 | 状态 | 备注 |
|---|---|---|
| 第十一届"创客中国"智能体与具身智能专题赛 | ❌ 报名截止 **2026-08-31** | 工信部网安中心 + 广东省工信厅主办，初赛 9 月上旬 |
| ITEC2026 具身智能行业赛（朝阳/火星加速器） | ❌ 报名截止 **2026-07-15** | 奖金池 5000 万+，总决赛 10 月底 |
| 2026 杭州国际具身机器人场景应用大赛 | ❌ **已结束**（5/15–16 举办） | 浙江省经信厅主办，宇树/云深处参与赛程设置 —— **你就在杭州，明年优先** |
| **ROSCon China 2026** | ✅ **仍可参与**（10/16–17 上海） | 有开源项目路演 + 招商；**学生票 799 / 早鸟 899 / 大会票 999 元 + 差旅** |

### 为什么我仍然不建议现在把竞赛当主路径

1. **评分表不友好**：具身智能赛道几乎都以整机 / 算法 / 场景应用为评审对象。RoboParts 是"数据 + 判定工具"基础设施，没有 demo 亮点、没有算法指标可打，评委很难给高分 —— 容易变成"陪跑 + 消耗精力"。
2. **精力已经分散**：你手上 SwarmLabs 正在报 GOAI、AI Grant、Kaggle ARC、腾讯、wisemodel 等一长串。再给 RoboParts 开一条竞赛线，是同一份精力拆给第二个项目。
3. **最关键：RoboParts 的瓶颈不是知名度，是产品价值还没验证**。
   当前诚实指标：跨厂商可直接比较的参数 **0 条**；机械接口对外声明率 **2.76%**（435 条机械可耦合实体中 12 条）。
   在这个状态下把项目推给更多业内人士，结果是**更多人来看一个还没验证的东西** —— 转化率低，且第一印象一旦形成很难改写。

> 顺序应该是：**先补 P0 机械/电气声明数据 → 让判定真的能用 → 再曝光**。
> 竞赛解决"让人知道"，解决不了"让人留下"。

| 优先级 | 动作 | 成本 | 可度量 |

## 四、本轮不采纳清单（留痕，避免下次重复讨论）

- **撮合型供应链平台对接**：是同赛道竞品，且需求为线下定向撮合、流量不经公网，无从外溢。
- **现在主打竞赛曝光**：窗口多数已关；评分表对基础设施类项目不友好；且与 SwarmLabs 竞赛线争夺同一份精力。核心数据缺口未补前，曝光会放大"未验证"的印象。
- **花钱渠道**：无计量基线前不投任何付费渠道（违反零成本优先，且无法算 ROI）。
