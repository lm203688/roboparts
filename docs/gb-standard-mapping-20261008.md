# 国标映射层（GB Standard Mapping）· 2026-10-08

> **性质**：这是**映射设计文档**，不是已完成的数据接入。
> 目的：把中国机器人/人形机器人国标体系映射到 RoboParts 的实体字段与判定层，
> 明确「哪些字段已对齐 / 哪些要新增 / 哪些属标准原文不在我方能力边界」。
> **纪律**：本仓无国标原文，故只登记**标准号 + 公开可核的适用范围**，
> **不臆造条款数值**；任何字段级对齐都以「能拿到标准原文/公开征求意见稿」为前提。

---

## 一、为什么这是当前最大机会窗口

2026 年是中国机器人标准化的「立规之年」：

- **《人形机器人与具身智能标准体系（2026 版）》**已由工信部标委会组织 120+ 家单位编制发布，
  设**六大板块**：基础共性 / 类脑与智算 / **肢体与部组件** / 整机与系统 / 应用 / 安全伦理。
- 一批关键标准正在**制定 / 征求意见 / 审查**中（见 §二），其中多条**直接对应 RoboParts 的核心资产**。
- 官方标准验证活动的实测结论：**「不少厂商产品技术文档关键参数缺失」**
  —— 这正是 RoboParts「三态诚实数据层」的价值锚点。

> 结论：RoboParts 应从「只对齐 ISO 9409-1」升级为**国标 + ISO 双轨对齐**，
> 并争取成为「模块通用信息模型」等标准的**开源参考实现**。

## 三、字段级映射（现行标准 → 实体字段）

> 仅列**已现行**标准中公开可核、且与现有字段语义明确对应的项。
> 「待原文」的条款一律不臆造。

| 标准 | 条款/维度 | 映射到实体字段 | 现状 |
|---|---|---|---|
| GB/T 43200-2023 | 关节性能（额定转矩、峰值转矩、定位精度、重复定位精度、回差…） | `actuators[].torque` / `precision` / `parameters` | 字段存在，**未标注标准号来源** |
| GB/T 43210.1-2023 | 模块化通用要求（模块定义、接口分类） | `category` / `entity_kind` / `mount_type` | 已有分类体系，**未挂标准号** |
| GB/T 38560-2020 | 通用驱动模块接口 | `electrical_interfaces` / `connector` | 已有电气接口层，**未挂标准号** |
| GB/T 39633-2020 | 一体式伺服电动机系统规范 | `actuators[]`（协作机器人执行器） | 可映射，未系统化 |
| ISO 9409-1 | 机械接口法兰 | `mechanical_interface.standard` | ✅ 已对齐（9 种标号 + 判定语法） |

**建议新增字段**（不改现有结构，additive）：

```jsonc
// 实体级：把「符合哪些标准」显式登记，而不是埋在自由文本里
"standard_conformance": {
  "assessed": true,
  "frameworks": [
    { "standard": "GB/T 43200-2023", "scope": "一体化关节性能", "status": "conforms|partial|unknown",
      "source_url": "…" }
  ]
}
```

> ⚠️ 现有 `standard_conformance` 已存在（`assessed` 等），上述为**扩展建议**，
> 需先核对现有 schema 再决定是并入还是新增子键——**不得破坏既有闸门**。

## 四、可立即执行的三件事（无需标准原文）

1. **把「模块通用信息模型」映射到实体 schema**（20255807-T-604，审查中）
   —— 这是契合度最高的一条：该标准的「模块信息模型」与 RoboParts 的实体 schema 是同一件事。
   产出：一份「RoboParts 实体字段 ↔ 模块信息模型」对照表，作为标准的**开源实现候选**提交。

2. **给现有字段补挂标准号**（GB/T 43200 / 43210.1 / 38560 / ISO 9409-1）
   —— 不改数据值，只在 `standard_conformance.frameworks[]` 登记「该字段依据哪个标准」。
   前提：字段值本身可核（沿用 `source_tier` 纪律）。

3. **跟踪在制标准的时间窗**
   —— 一体化关节接口标准即将征求意见；「模块通用信息模型」在审查。
   在这两个窗口内把 schema 对齐，可抢占「标准开源参考实现」位置。

## 五、诚实边界（不得省略）

- **本仓不持有任何国标原文**。本文件的标准号与状态来自公开报道与全国标准信息公共服务平台
  （`std.samr.gov.cn`）的**计划/状态信息**，非标准正文。
- 「字段可映射」指**语义可对应**，不等于「已按标准条款逐条校验」——
  条款级一致性须以标准原文为准，本仓当前做不到。
- 参与标准共建、提交开源实现属**需人工推进**的动作（联系标委会/北京人形等），
  非本仓可自动完成。
- 本文件是**方向性映射**，不构成任何合规声明；对外不得表述为「符合 GB/T XXXX」。
