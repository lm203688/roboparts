## 1. 一句话方向（判据的唯一上级）

> **RoboParts = 具身系统「组合」的形式化底座。**
> 把 **脑（神经控制）× 体（物理零件）× 智（学习策略）** 做成**机器可校验的组合**，
> 并让整条链路可溯源。
> **不是零件数据库，不是兼容性网站**——零件 registry 只是载体，
> 真正的产出是 **兼容判定引擎 + 形态图 + 溯源层**。

一句话检验法：**这件事是在「让组合变得可校验」，还是在「让列表变得更好看」？**
后者不符合方向，无论它看起来多有用。

## 2. 决策闸门（核心 · 三问）

任何动作开始前问三问，**三否即丢弃**，不因沉没成本续投：

1. **是否产出别人做不出的东西？**（依赖本项目独有资产，而非通用能力）
2. **是否定义了新问题？**（不是回答一个已被回答过的旧问题）
3. **是否更接近「具身组合演算」？**（service 方向，不是旁支）

判定示例（用于消除歧义，不是穷举）：

| 动作 | Q1 | Q2 | Q3 | 结论 |
|---|---|---|---|---|
| 形态图（parts=nodes, interfaces=typed edges） | ✅ 依赖已校验 registry | ✅ 「已校验兼容的零件图」此前无标准 | ✅ 是组合的输入形式 | **做** |
| 跨层 PROV-O 溯源 | ✅ 脑侧+体侧拼接 | ✅ 端到端溯源全球无系统做到 | ✅ 组合可审计 | **做** |
| Croissant 元数据 | ❌ 标准动作，谁都能做 | ❌ 只是格式转换 | ❌ 只是入口 | **只作为副产品**，不占方向位 |
| 再写一篇「XX 零件推荐」GEO 文 | ❌ 通用内容 | ❌ 旧问题 | ❌ 无关 | **不做** |
| 自建 GPU 训练栈 | ❌ 拼算力不是拼创新 | ❌ 旧问题 | ❌ 无关 | **不做**（对接 LeRobot） |

## 3. 不做什么（负向边界 · 硬性）

| 不做 | 理由 |
|---|---|
| ❌ 造脑 / 连接组仿真 | 重资产、强学术壁垒；且非本域 |

| ❌ 造仿真器 / 训练栈 | 对接 Isaac/MuJoCo/LeRobot，不另起炉灶 |

| ❌ 商业化优先 | license 子站冻结，支付链路维持现状不扩展 |
| ❌ 与 NCP 竞争 | NCP 是**运行时线协议**，本项目是**静态类型/注册层**，互补 |

## 5. 硬性约束（不变）

1. **机器可读优先**：API > HTML > 文档。人看的页面是派生物，不是真相源。
2. **零预算**：不调用付费 API，不建 GPU 集群。
3. **单一真相源**：数字一律现算（`onboarding_block.facts()`），禁手填副本。
4. **溯源必做**：每份对外数据必须挂得出出处链（Tier A/B/C 分级不注水）。
5. **fail-closed**：不可判定 → 判「未知」，**不判通过**。宁可崩，不可假绿。
6. **闸门须有阴性对照**：只测绿路径的闸门等于没闸门（本仓病史见 §7）。

## 6. 诚实边界（必须随方向一起传播，不许省略）

### 6.1 「5.69%」的合法表述（**本轮收窄**）

**禁止再这样写**：「5.69% 是 ISO 9409-1 覆盖边界的实证证据」。

**改为此表述**：
> 5.69% 是**「公开可判定粒度上的标准登记率」**。其低值由两种**未区分**的成因共同构成：
> **(i) 厂商未公开规格**（真数据缺口）与 **(ii) 零件本就采用自研/专有接口**（生态碎片化，非缺口）。
> 在完成 (i)/(ii) 分类之前，**不得**把它单独当作标准覆盖边界的实证证据对外主张。

**收窄依据**（两条独立证据，非推测）：
- **自查反例**：`ACT-001 DYNAMIXEL XM540-W270-T` 的
  `mechanical_interface.status = "partial"`，其 `declared_note` 明写
  「ROBOTIX X 系列专有安装体系……**非 ISO 9409-1 法兰**」。
  ⇒ 该零件**有**机械接口，只是不标准。它的「未声明」不是 ISO 9409-1 的边界问题。
- **本地决策模型反驳**：Laya 421M 对「低声明率是否更应刻画为关于标准的诚实实证发现」
  以 **conf=0.9226** 回答 **否（P(true)=0.0774）**。高置信度信号，作为反方意见采纳。
  （同批 3 个 choice 问题 conf 仅 0.014–0.030，低于该模型可用区间，**未采信**；见留痕文件。）

**残留价值**：把 (i)/(ii) 分类**做出来**，是一个尚未做、可做、没人做过的研究动作。
方向从「把缺口当证据」改为「把**缺口的成因分类**当研究」。

### 6.2 其他边界

- **形态图 ≠ 完整图**：只有 25 个实体有可判定接口。图为**稀疏且带 unknown 类型**，
  不是一张「全连通兼容图」。任何下游消费者都会读到 unknown，须自行处理。
- **`compatibility_matrix.json` 的 pairs 不与实体绑定**，是人工示意。
  生产判定走 `/api/compatibility?a=&b=` 实时计算。**不得**把示意对当判定证据。
- **D5（组合演算）是多年期**：范畴论/Lean 形式化，独立开发者必须分三步走
  （轻量原型 → 方法论文 → 视反馈上重武器）。**不许一上来写 Lean 定理证明。**
- **算力是真实约束**：D4 协同设计需仿真 loop，必须小规模起步 + 离线预计算。

3. **改 §6 边界** → 属对外口径变更，须同步 `positioning_contract.py` 与线上回探。
4. 任何改动必须能被下一个人**独立复现**（给命令/给路径/给哈希），否则不算证据。
