兼容性可视化 · RoboParts

借鉴 rerun.io 的"可探索可视化"范式（纯前端 Canvas 复刻，不引入 Rust 全栈）：把兼容性裁决引擎的判定过程、零件组合的图谱关系、以及库内声明率缺口三件事变得可看、可点、可懂。所有渲染在浏览器本地完成，零外部依赖。

① 兼容性判定过程

给定两个零件，引擎在 protocol / electrical / mechanical / software 四维逐维裁决，再合成总体结论。这里把"过程"画出来——绿=兼容，红=冲突，灰=双方均无声明（证据不足，不等于不兼容）。

输入两个真实 ID 后点击"判定"。

② BOM 兼容图谱

粘贴一组零件 ID（≤12 个，逗号或换行分隔），引擎计算两两兼容性，绘制力导向图谱：绿边=兼容、红边=冲突、灰边=证据不足。鼠标悬停查看节点详情。

③ 声明率快照（数据飞轮基线）

实时统计库内各维度"被声明"的比例。机械/电气接口声明率极低，正是飞轮要补的缺口——本图会随真实 BOM 贡献流入而逐次刷新，成为可追踪的时间轴起点。
