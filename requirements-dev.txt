# RoboParts 本地开发依赖（用于让本地 python scripts/ci_gate.py 拿到与线上 CI 一致的绿灯）
#
# 为什么需要这份文件：
# - .github/workflows/ci.yml 里显式 `pip install PyYAML`（因为「GitHub 配置 YAML 可解析」闸门

#   制造「本地红/线上绿」的假分歧，诱导排查者误判方向。
# - 2026-10-11 报告 P2-1 明确记录此问题。

PyYAML>=6.0,<7.0

# usd-core 25.11+ 提供 cp312 manylinux wheel；本地 Windows 用 cp313/cp314 wheel。
# pxr 不可用时闸门 fail-closed 报红（防 P0-9「命令未运行却算测过」假绿）。
