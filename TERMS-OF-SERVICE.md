## 2. Description of Service

### 2.1 Service Overview
RoboParts provides a neutral composition checking layer for open-source robot builders, determining whether parts can be assembled/compatibly used/exchanged, and generating verifiable three-state conclusions (can/cannot/unknown).

### 2.2 Service Features
- **Compatibility Checking**: Verify mechanical compatibility between robot parts
- **Data API**: Access to structured robotics data and compatibility information
- **3D Adapter Generation**: Generate printable adapter files for incompatible parts
- **Research Tools**: Tools for robotics research and analysis
