❓ 常见问题
积分有什么用途？
积分用于调用 RoboParts API 接口，每次成功的 API 请求消耗 1 个积分。通过积分可以查询 768 条机器人零部件实体数据（其中 482 条已通过溯源核验，未核验条目默认不进入选型结果）、进行高级搜索、获取跨品类关联信息等。
支付后积分多久到账？
微信/支付宝扫码支付成功后，积分通常在几秒内自动到账。如果超过 5 分钟未到账，请截图支付凭证联系我们人工处理。
积分会过期吗？
不会。已充值的积分永久有效，没有过期时间限制。
如何获取 API Key？
在首页 API 文档区域，通过 POST /api/register 接口传入邮箱即可免费获取 API Key，注册即赠送 100 积分用于体验。
支持哪些支付方式？
国内用户：通过虎皮椒支付网关，支持微信支付和支付宝扫码付款（CNY 结算），支付安全由网关保障，所有交易均为即时到账。
可以申请退款吗？
由于积分属于虚拟商品且即时到账，已充值的积分不支持退款。建议先使用免费赠送的 100 积分体验后再购买。
